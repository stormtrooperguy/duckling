DETAILED COMPONENT CONNECTIONS
================================

1. LED STRIP (WS2812B - 4 LEDs: 1 inline repeater + 3 in head)
   ===============================================================

   Chain order (DIN flows left-to-right):

   ┌──────────┐    ┌──────────────────────────────┐
   │ REPEATER │    │  HEAD                        │
   │ (off)    │───▶│  Eye 1 ─▶ Eye 2 ─▶ Flashlight│
   └────┬─────┘    └──────────────────────────────┘
        │ DIN of first LED (repeater)
        │
        │           ┌─────────────────┐
        │           │ GND ◀── common ground with 5V supply
        │           │ GPIO 5 (DATA)   │  ESP32
        └───────────┤                 │
                    └─────────────────┘

   Power (all 4 pixels): 5V and GND from the regulated 5V supply,
   with that supply's GND bonded to ESP32 GND.

   Notes:
   - WS2812B can run on 3.3V or 5V; this build uses 5V external supply
   - The repeater pixel sits as close to the controller as practical,
     then a single long data wire runs to the head. Its job is to
     re-clock the WS2812 data stream so the head pixels see a clean
     signal; firmware holds it black at all times.
   - Add 470Ω resistor on data line if using 5V LEDs with 3.3V logic
   - Add 1000µF capacitor across 5V/GND for power stability

   - RX from ESP32 ← TX from Maestro
   - Baud rate: 9600


3. DFPLAYER PRO (Optional - Serial2)
   ================================================

   ┌────────────────────┐
   │  DFPlayer Pro      │
   │  (DF1201S, 128MB)  │
   │  [USB-C for files] │
   │                    │
   └─┬──┬──┬────┬──┬──┬─┘
     │  │  │    │  │  │
    RX TX GND  VIN DAC_L DAC_R
     │  │  │    │  │  │
     │  │  │    │  │  │       ┌─────────────────┐
     │  │  │    └──┼──┼───────┤ 5V rail         │
     │  │  │       │  │       │                 │
     │  │  └───────┼──┼───────┤ GND             │  ESP32
     │  └──────────┼──┼───────┤ GPIO 18 (RX2)   │  Serial2
     └─────────────┼──┼───────┤ GPIO 19 (TX2)   │
                   │  │       └─────────────────┘
                   │  │           DAC outputs go to amplifier:
                   ▼  ▼
              ┌─────────────────────┐
              │  DROK 5W+5W Mini    │
              │  Audio Amplifier    │◀── 5V / GND from same rail
              │  (PAM8403-class)    │
              └─┬─────┬───┬─────┬───┘
                │ L+  │L− │ R+  │R−
                ▼     ▼   ▼     ▼
             ┌────────┐  ┌────────┐
             │ LEFT   │  │ RIGHT  │
             │ 2.5W   │  │ 2.5W   │
             │ 36mm   │  │ 36mm   │
             └────────┘  └────────┘

   Notes:
   - NO resistor needed on the RX line. The DF1201S's UART inputs
     are 3.3V-tolerant (unlike the YX5200-based DFPlayer Mini,
     which needed a 1kΩ here to limit clamp-diode current).
   - Power: 5V on VIN works fine from anywhere on the rail. The
     Pro is much less sensitive to power quality at init than the
     Mini was; a flying wire from the buck converter is OK.
   - Files load via USB-C: connect the Pro to a Mac, it mounts as a
     removable drive. Drop files at the root in numerical order
     (0001.wav, 0002.wav, …). Run `dot_clean -m` on the volume
     before ejecting to strip macOS AppleDouble cruft that confuses
     the chip's enumeration. Disconnect USB-C, reset ESP32.
   - The chip supports MP3, WAV, FLAC, AAC, WMA, APE. Much more
     permissive than the YX5200-based Mini was about WAV variants.
   - The built-in SPK_1/SPK_2 amp is unused here — DAC_R/DAC_L
     line-level out feeds the DROK amp instead, which then drives
     the 36mm speakers with proper headroom.
   - If init fails, swap RX/TX wires at the Pro side. Silkscreen
     labels can still be inconsistent across batches.
   - DROK amp is also powered from the 5V rail. Class-D switching
     can inject supply noise — add a 100–470µF bulk cap at the
     amp's VCC pin if you hear hiss/whine.
   - Baud rate: 115200


PIN ASSIGNMENT TABLE
====================

ESP32 GPIO    | Component         | Signal      | Notes
--------------|-------------------|-------------|---------------------------
GPIO 5        | LED Strip         | Data In     | WS2812B data line
GPIO 16       | Maestro           | RX (ESP)    | Serial1 - from Maestro TX
GPIO 17       | Maestro           | TX (ESP)    | Serial1 - to Maestro RX
GPIO 18       | DFPlayer Pro      | RX (ESP)    | Serial2 - from DFPlayer Pro TX
GPIO 19       | DFPlayer Pro      | TX (ESP)    | Serial2 - to DFPlayer Pro RX (no resistor needed)
GND           | All Components    | Ground      | Common ground required
5V            | LED Strip, MP3   | Power       | From 5V buck converter
8V            | Maestro           | Power       | From 8V buck converter

IMPORTANT: GPIO 9 and 10 are used for flash memory and will cause boot failures!
           GPIO 18 and 19 are safe general-purpose pins (VSPI defaults
           but VSPI is never explicitly initialized in this firmware).


POWER DISTRIBUTION (PRODUCTION SYSTEM)
========================================

System uses 18V battery with two buck converters:

                           18V BATTERY
                                │
                    ┌───────────┴────────────┐
                    │                        │
         ┌──────────┴────────┐    ┌──────────┴────────┐
         │  BUCK CONVERTER   │    │  BUCK CONVERTER   │

            5V RAIL │                8V RAIL │
                    │                        │
         ┌──────────┼──────────┐             │
         │          │          │             │
         │          │          │             │
    ┌────┴─────┐ ┌─┴────┐ ┌───┴──────┐ ┌────┴─────┐
    │  ESP32   │ │ LED  │ │ MP3 Player │ │ MAESTRO  │
    │  Board   │ │Strip │ │   Mini   │ │  Servo   │

Power Budget:
  5V Rail: ESP32 (500mA) + LEDs (180mA) + MP3 Player (50mA) = ~750mA
  8V Rail: Depends on servos (typically 3-5A for multiple servos)

STEP-BY-STEP WIRING CHECKLIST
==============================

PRODUCTION SYSTEM (with 18V Battery):

□ Step 0: Setup power system
  - Connect 18V battery to both buck converter inputs
  - Configure first buck converter for 5V output (verify with multimeter)
  - Configure second buck converter for 8V output (verify with multimeter)
  - Connect battery negative to common ground rail

□ Step 1: Connect all ground connections first
  - Battery negative (GND) to ground rail
  - Both buck converter grounds to ground rail
  - ESP32 GND to ground rail
  - LED Strip GND to ground rail
  - MP3 Player GND to ground rail (if using)
  - Maestro GND to ground rail (if using)

□ Step 2: Connect power rails
  - 5V buck converter output to 5V distribution rail
  - 8V buck converter output to Maestro power input
  - ESP32 5V pin to 5V rail
  - LED Strip VCC to 5V rail
  - MP3 Player VCC to 5V rail (if using)

□ Step 3: Connect LED data
  - LED Strip DIN to ESP32 GPIO 5

□ Step 4: Connect MP3 Player (if using)
  - ESP32 GPIO 19 → DFPlayer Pro RX (direct, no resistor needed)
  - ESP32 GPIO 18 → DFPlayer Pro TX (direct)
  - 5V rail → DFPlayer Pro VIN (any clean 5V source)
  - DFPlayer Pro GND → ESP32 GND (common ground)
  - DFPlayer Pro DAC_R → DROK amplifier R input (line level)
  - DFPlayer Pro DAC_L → DROK amplifier L input (line level)
  - DROK amplifier VCC/GND → 5V rail / common ground
  - DROK amplifier L+/L− → left speaker  (2.5W, 36mm)
  - DROK amplifier R+/R− → right speaker (2.5W, 36mm)

□ Step 5: Connect Maestro (if using)
  - ESP32 GPIO 17 → Maestro RX
  - ESP32 GPIO 16 → Maestro TX

□ Step 6: Double-check all connections
  - Verify no short circuits
  - Confirm polarity on power connections
  - If MP3 init fails, swap DFPlayer Pro RX/TX (silkscreen labels can be inconsistent)

□ Step 7: Test
  - Upload code
  - Open Serial Monitor (115200 baud)
  - Verify initialization messages


BUCK CONVERTER RECOMMENDATIONS
================================

For 5V Rail (ESP32, LEDs, MP3 Player):
  Input: 18V DC
  Output: 5V DC regulated
  Current Rating: 2A minimum (3A recommended)
  Features: Adjustable output, overcurrent protection, heat sink
  Example: LM2596 based modules, XL4015 modules

For 8V Rail (Maestro Servos):
  Input: 18V DC
  Output: 8V DC regulated
  Current Rating: 3-5A minimum (depends on servos)
  Features: High current capability, adjustable output, thermal protection
  Example: LM2596 (for lighter servo loads), XL4016 (for heavy loads)

Important:
  - Verify output voltage with multimeter BEFORE connecting components
  - Buck converters generate heat - ensure adequate cooling/heat sinking
  - Add fuses: 2A on 5V output, appropriate rating on 8V output
  - Use thick wire (18-20 AWG) for battery and high-current connections
  - Mount converters securely with good ventilation


BATTERY SAFETY
===============

18V Battery Considerations:
  - Use appropriate battery type (LiPo 5S, Li-ion pack, etc.)
  - Ensure battery has proper protection circuit (BMS)
  - Check battery capacity matches current draw
  - Add master power switch for easy shutdown
  - Use appropriate connectors (XT60, Deans, etc.)
  - Never short battery terminals
  - Monitor battery voltage during operation
  - Disconnect battery when not in use

Suggested Battery Capacity:
  - Minimum: 2000mAh (for short operation)
  - Recommended: 3000-5000mAh (for extended operation)
  - Calculate runtime: Capacity (mAh) / Total Current Draw (mA)


COMMON MISTAKES TO AVOID
=========================

Power Related:
❌ Not connecting common ground (battery negative must connect to all grounds)
❌ Buck converter output voltage not verified before connecting components
❌ Insufficient current rating on buck converters
❌ No fuses on power rails
❌ Battery polarity reversed
❌ Powering servos from ESP32 5V pin (will cause brownout/damage)

Wiring Related:
❌ Swapping TX/RX connections (remember: TX → RX, RX → TX)
❌ Wrong baud rate settings (Maestro: 9600, DFPlayer Pro: 115200)

Data Related:
❌ Audio files not named correctly (should be 0001.wav/mp3, 0002.wav/mp3, etc., at the Pro's storage root)
❌ Audio files written out-of-order on the Pro's storage (chip uses physical write order for playFileNum)
❌ macOS AppleDouble (`._*`) sidecar files left on the Pro after a USB-C transfer — run `dot_clean -m` before ejecting
❌ MAESTRO_ENABLED set to false when servos are connected


TROUBLESHOOTING BY LED BEHAVIOR
================================

LEDs don't light:
- Check GPIO 5 connection
- Verify LED strip has power
- Check LED_PIN setting in code
- Try different COLOR_ORDER setting

LEDs wrong colors:
- Try COLOR_ORDER: RGB, GRB, or BRG
- Check voltage (WS2812B works at 3.3V or 5V)

LEDs flicker:
- Add capacitor (1000µF) across power lines
- Check power supply capacity
- Add resistor (470Ω) on data line
